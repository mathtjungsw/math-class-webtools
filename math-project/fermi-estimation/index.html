페르미 추정이란?

정확한 자료가 없거나 직접 세기 어려운 수량을 몇 개의 요소로 나누고, 각 요소에 합리적인 값을 가정하여 전체 규모를 추정하는 방법입니다. 서로 다른 가정에서 서로 다른 결과가 나올 수 있으므로, 답 자체보다 분해 방식·가정의 근거·단위·결과 검토가 중요합니다.

이 웹툴은 수업용 고정 자료와 학생의 가정을 이용하며, 실제 통계값을 확정적으로 제시하는 도구가 아닙니다.
