  1. FFmpeg Windows builds에서 release essentials ZIP 파일을 받습니다.
  2. 압축을 풀고 폴더 안의 bin 경로를 Windows 환경 변수 Path에 추가합니다.
  3. PowerShell을 새로 열어 ffmpeg -version이 표시되는지 확인합니다.
  4. 이 프로젝트에서 다시 npm start를 실행합니다.
