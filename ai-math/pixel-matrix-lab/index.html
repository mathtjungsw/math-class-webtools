수학 설명

행렬에서 합성곱, 그리고 CNN까지

이미지 = 행렬

흑백 이미지는 각 픽셀의 명도를 원소로 갖는 행렬입니다. 0은 검정, 255는 흰색이며 행과 열은 픽셀의 위치를 나타냅니다.

합성곱 = 지역 계산

3×3 이웃과 커널의 같은 위치끼리 곱한 뒤 모두 더합니다. 커널이 한 칸씩 이동하며 출력 행렬의 원소를 만듭니다.

효과가 달라지는 이유

양수는 밝기나 특징을 더하고, 음수는 이웃과의 차이를 강조합니다. 평균 커널은 부드럽게, 차이 커널은 경계를 선명하게 만듭니다.

CNN과의 연결

CNN도 작은 커널로 지역 특징을 찾지만, 이 실험처럼 사람이 값을 정하는 대신 데이터로 유용한 값을 학습합니다. 이 도구 자체는 AI를 학습하지 않습니다.

경남수학교육소식의 ‘흑백 이미지 속 픽셀’과 ‘행렬 시각화·이미지 커널 필터 체험’ 수업 아이디어를 바탕으로 구성했습니다.
