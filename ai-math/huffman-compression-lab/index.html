허프만 압축 실험실 설명서

무엇을 배우나요?

문자 출현 빈도를 확률로 해석하고, 매 순간 가장 작은 두 묶음을 선택하는 그리디 알고리즘이 전체 부호 길이를 줄이는 과정을 탐구합니다.

  1. 1. 텍스트 준비예시를 선택하거나 한글·영문·숫자·기호가 섞인 문장을 입력하고 ‘빈도 분석 시작’을 누릅니다.
  2. 2. 빈도 관찰출현 횟수·상대도수·막대그래프를 보고 어떤 문자가 짧은 코드를 받을지 먼저 예측합니다.
  3. 3. 트리 생성‘다음 한 단계’ 또는 ‘자동 재생’으로 가장 작은 두 노드가 합쳐지는 우선순위 큐를 관찰합니다. 동률이면 유니코드 순서를 따릅니다.
  4. 4. 코드 왕복완성된 트리의 왼쪽 0·오른쪽 1 경로를 읽고, 인코딩된 비트열을 전체 또는 한 비트씩 디코딩합니다.
  5. 5. 압축 비교고정 길이와 허프만 부호의 총 비트 수, 절감률, 엔트로피와 평균 부호 길이를 비교합니다.
  6. 6. 미션·기록직접 가장 작은 두 카드를 선택하고, 탐구 질문의 예측·관찰·결론을 기록한 뒤 CSV·TXT·JSON으로 저장합니다.

수업 운영 예시

도입 5분 압축 원리 예측 → 탐구 25분 트리와 왕복 실험 → 정리 15분 문장별 압축률 비교와 그리디 원리 설명

꼭 구분하세요

화면의 비트 수는 문자 집합에 붙인 이론적 부호 길이입니다. 실제 파일 크기에는 UTF-8 표현, 트리·코드표와 파일 형식 정보가 더해집니다.

접근성과 조작

모든 활동은 드래그 없이 클릭과 키보드로 가능합니다. Tab으로 이동하고 Enter 또는 Space로 버튼을 실행할 수 있으며, 설명서는 Esc 키로 닫을 수 있습니다.
