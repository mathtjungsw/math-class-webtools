# 시간의 좌표 · 역사 탐험

미리 조사한 장소의 선사·역사 자료를 따라 서기 1950년까지 탐험하는 학습 게임입니다. `index.html` 한 파일에 조사 데이터, 지도, 스타일과 실행 코드가 들어 있습니다. Google 로그인·Sheets·Apps Script 또는 자료 조회 서버 없이 실행합니다.

## 실행

- 공개 주소: https://mathtjungsw.github.io/math-class-webtools/math-history/random-location-history/
- `index.html`을 브라우저에서 직접 엽니다. 인터넷 없이도 게임과 개략지도가 동작합니다.
- 출처 링크와 실제 지도 링크를 열 때는 인터넷이 필요합니다.
- GitHub Pages에는 이 폴더의 `index.html`을 올리면 됩니다. 로컬 파일 수정만으로 공개 사이트가 갱신되지는 않습니다.
- 화면의 `HTML 저장`은 데이터가 포함된 실행 파일을, 출처 모음의 `조사 데이터 JSON 저장`은 해당 장소 자료를 내려받습니다.

로컬 미리보기는 저장소 루트에서 실행합니다.

```powershell
node math-history/random-location-history/tools/preview.mjs
```

주소: `http://127.0.0.1:8799/`

## 수록 자료와 기능

첫 지역은 **진주 남강 유역**입니다. 내촌리·상촌리·대평리·평거동과 진주성 일대의 자료를 함께 다룹니다. 대표 좌표는 진주성 관광정보의 북위 35.189746°, 동경 128.080276°이며, 유역의 중심이나 최초 거주 지점을 뜻하지 않습니다.

- 53건의 연대 기록, 4건의 연도 미확정 해설, 45개 출처를 내장했습니다.
- 여섯 개의 시대 이야기에 `짧게 읽기`, `상세히 보기`, `깊이 읽기`를 제공합니다. 예상 분량은 약 1분·2분·6~7분이며 본문 600자/분 기준으로 계산합니다. 깊이 읽기는 각 3,000자 이상입니다.
- 현재 기록의 버튼이나 시대별 목록에서 글을 열고, 차례로 이동하거나 다음 시대의 이야기를 이어 읽을 수 있습니다. 글을 읽는 동안 시간 재생은 멈춥니다.
- 연구 논문·사료·공공기관 자료의 확인 범위와 근거를 기록별로 표시합니다.
- 1개월/초, 1년/초, 10년/초, 100년/초, 1,000년/초 속도 조절, 이전·다음 기록, 시간 이동, 검색을 지원합니다.
- 수록 기록이 없는 구간 스킵과 각 기록에서 4초 읽기를 선택할 수 있습니다. 빠른 재생도 중간 기록에서 멈추므로 순서를 놓치지 않습니다.
- 지원되는 브라우저에서는 마지막 시점과 설정을 해당 브라우저에 저장합니다. 자동 재생은 하지 않습니다.
- 진주 남강과 이스탄불 중에서 선택·추첨합니다. 장소를 바꾸면 해당 장소의 기록·읽기·출처·지도가 함께 바뀝니다.
- 주변 8방향 비교는 자료 준비 상태를 표시합니다. 실제 비교 역사는 추가 조사 후 넣어야 합니다.

**이스탄불**은 역사 반도·예니카프·금각만·보스포루스의 관계를 다룹니다. 대표점은 술탄아흐메트 북위 41.008°, 동경 28.983°이며 최초 거주 지점이 아닙니다. 58개 연대 기록, 3개 연도 미확정 해설, 42개 출처와 여덟 시대의 세 단계 읽기를 수록했습니다. 깊이 읽기는 각 3,000자 이상으로 화면에서 예상 6분으로 표시합니다. 기원전 약 6500년의 확인 자료부터 시작하며 최초 거주 연도는 미확정입니다.

진주의 최초 거주 연도는 미확정입니다. 시간축은 확인한 신석기 자료의 대표 배치 시점인 기원전 약 3000년에서 시작하며, 더 이른 흔적은 해설에서 읽습니다. 보정 연대 범위나 연구에서 제안한 시기를 확정 발생일·존속 기간으로 바꾸지 않습니다. 음력 날짜도 검증 없이 양력으로 환산하지 않습니다.

모든 장소는 **1950년까지** 진행합니다. 1950년은 방사성탄소연대 BP의 기준년이지만, 미보정 BP 값을 단순히 빼서 달력 연도로 사용하지 않습니다. 자료 공백은 사람이나 역사가 없었다는 뜻이 아닙니다.

## 장소·자료 업데이트

조사 원본과 보고서는 `research/`에 있습니다. 첫 지역의 데이터는 `research/jinju-namgang/location.json`, 시대별 원고는 같은 폴더의 `readings.json`입니다. 새로운 장소도 이 두 구조로 조사하고, 출처와 공간 범위 및 연대의 불확실성을 확인합니다. 모든 연대 기록을 한 시대의 읽기에 연결해야 빌드됩니다.

1. 조사 JSON을 추가하거나 기존 내용을 보완합니다.
2. 새 장소는 `tools/build-static.mjs`의 `locationFiles` 목록에 추가합니다.
3. 아래 빌드와 검증 명령을 실행합니다.
4. 생성된 `index.html`을 열어 확인하고 GitHub Pages에 갱신합니다.

`displayAnchorYear`와 `displayAnchorMonth`는 불확실한 자료의 읽기 순서에 사용하는 배치값입니다. 실제 발생 연월로 표시하지 않습니다. 예를 들어 정확한 월일이 확인되지 않은 1950년 촉석루 소실은 마지막에 배치하고 별도 안내를 표시합니다. 국가·주변 지역의 배경과 진주 현장의 사건도 구분합니다.

```powershell
node math-history/random-location-history/tools/build-static.mjs
node --test tests/random-location-history-static.test.js tests/catalog-common-features.test.js tests/tool-thumbnails.test.js
```

화면 원본은 `tools/static-template.html`, `tools/static-style.css`, `tools/static-app.js`입니다. 시간 계산은 `tools/static-core.js`가 담당합니다. 생성된 HTML을 직접 고치면 다음 빌드에서 덮어씌워지므로 원본을 수정하세요.

기존 자동 수집·Sheets 연동 파일은 보존되어 있지만 현재 정적 게임에서는 불러오지 않습니다.

## 지도와 출처

해안선은 [Natural Earth](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)의 public domain 데이터를 단순화한 현재 해안선 개략지도입니다. 과거 해안선·정밀한 유적 위치를 나타내지 않습니다.

개별 역사 출처는 게임의 출처 모음과 조사 JSON에 포함되어 있습니다. 논문 본문, 공개 초록, 번역 사료, 기관 설명 등 실제로 확인한 수준을 구분합니다. 원문을 대량 복제하지 않고 필요한 내용을 재서술했습니다.
