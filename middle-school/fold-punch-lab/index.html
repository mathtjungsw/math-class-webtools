접기는 반사변환, 펼치기는 그 반사변환의 역순 적용입니다.

HOW TO USE

대칭 실험실 설명서

  1. 1
    접기선과 방향을 고르세요.

    중앙선·대각선·1/4 격자선 중 하나를 고르고 유지할 쪽을 선택합니다. 접기 이력과 최대 층 수가 자동으로 기록됩니다.

  2. 2
    한 번만 뚫거나 자르세요.

    펀치 모드에서는 접힌 종이 안을 누르고, 자르기 모드에서는 시작점과 끝점을 누릅니다. 종이 밖의 펀치와 만나지 않는 절단선은 실행되지 않습니다.

  3. 3
    역순으로 펼치세요.

    ‘한 단계씩 펼치기’를 누르면 이번 단계에 생긴 반사상이 파란색으로 표시됩니다. 번호로 원본과 대응점을 비교하세요.

  4. 4
    예상과 결과를 설명하세요.

    2ⁿ과 실제 결과 수가 다른 경우, 접힌 선·경계·서로 겹친 위치가 원인인지 확인하고 탐구 기록에 남깁니다.

완성 무늬에서 거꾸로 생각하기

  • 목표 점선 무늬의 대칭축부터 찾습니다.
  • 쉬움·보통·도전 난이도를 선택하고 최소 접기 횟수에 도전합니다.
  • 힌트는 대칭축 → 첫 접기선 → 점의 반사 순서로 제공됩니다.
  • 자동 채점은 목표와 실제 구멍의 위치를 허용오차 안에서 비교합니다.
분석 읽는 법

예상 2ⁿ은 모든 반사상이 서로 다를 때의 최댓값입니다. 실제 수가 작다면 축 위의 점이 자기 자신으로 겹치거나, 서로 다른 반사 경로가 같은 위치에 도달한 것입니다.

수업 운영 예시

  1. 예상

    펼치기 전에 구멍 수와 위치를 개인 또는 모둠별로 기록합니다.

  2. 실험

    한 단계씩 펼치며 새 반사상과 대칭축에서의 거리를 확인합니다.

  3. 설명

    2ⁿ보다 적어진 사례를 축 위·경계·중복으로 분류합니다.

교사 설정

최대 접기 횟수, 허용 접기선, 제한시간, 힌트를 지정할 수 있습니다. JSON 저장·불러오기로 학급별 문제 프리셋을 재사용하세요. 학생 기록은 브라우저 안에서만 처리되며 활동 JSON과 인쇄물로 저장할 수 있습니다.
