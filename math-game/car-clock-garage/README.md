# 부릉부릉 차고

국산 자동차 사진을 보고 글로 된 객관식 답을 고르고, 자동차 5문제마다 아날로그 시계 1문제를 푸는 노트북 중심 정적 웹앱입니다. 기본은 차종 이름 3지선다와 5분 단위 시계입니다.

## 실행

`index.html`을 브라우저로 여세요. `photos`, `cars.js`, `core.js`, `app.js`, `style.css`가 같은 폴더에 있어야 합니다. 별도 설치·로그인·AI API·DB가 필요하지 않습니다. 게임 중 외부 사진 서버에 요청하지 않습니다. 사진 출처 링크만 외부 사이트로 연결됩니다.

한 파일 버전은 저장소 루트에서 `python -X utf8 math-game/car-clock-garage/tools/build_standalone.py`로 생성합니다. `outputs/car-clock-garage/부릉부릉-차고.html`에 사진·코드·출처를 모두 포함하므로 이 파일만 복사해 실행할 수 있습니다. 브라우저 저장은 주소마다 별도이므로 버전·위치를 옮길 때는 JSON 백업으로 기록을 옮기세요.

저장소 루트에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/math-game/car-clock-garage/`로 접속하거나, 기존 저장소와 함께 GitHub Pages에 배포할 수 있습니다. 파일로 직접 연 경우와 HTTP·HTTPS로 연 경우의 브라우저 저장 공간은 서로 다릅니다. 파일 주소에서의 저장 동작은 브라우저에 따라 다를 수 있어 수업에서는 HTTP·HTTPS 접속을 권장합니다.

## 게임과 보상

- 자동차 5문제를 **완료**하면 시계 1문제가 나옵니다. 오답은 순서를 바꾸거나 진행을 초기화하지 않습니다.
- 자동차 처음 정답 +10 XP, 시계 처음 정답 +20 XP. 힌트 사용·오답 후 정답은 각각 +5 XP, +10 XP입니다. 반복 클릭·재로딩은 경험치를 중복 지급하지 않습니다.
- 다음 문제는 학생이 버튼을 눌러 넘깁니다. 시간제한과 경험치 차감은 없습니다.
- 모닝 → 레이 → 아반떼 → K5 → 아이오닉 5 → 쏘렌토 → 그랜저 → G80 → GV80의 9단계 차고 보상입니다. 기존 자동차도 계속 선택할 수 있습니다.
- 자동차 난이도는 이름·세대·세대 출시연도·혼합, 선택지는 2~4개입니다. 확보된 세대 쌍은 2지선다로 출제합니다. 시계는 5분·정각/30분·정각으로 조절할 수 있습니다. 설정은 다음 문제부터 적용됩니다.
- 시침은 분에 따라 이동합니다. 시계는 SVG로 직접 그려 외부 이미지가 필요하지 않습니다.
- 정답 효과음은 기본 해제입니다. 화면 효과를 끌 수 있고 시스템의 동작 줄이기 설정도 따릅니다.

## 사진·연도 자료

20개 차종, 24개 사진입니다. 모닝·아반떼·쏘나타·그랜저는 서로 다른 세대 사진을 포함합니다. 현대·기아·제네시스 차량이며 일부 사진은 해외에서 촬영되었습니다. 촬영 국가·등록 연식과 국내 세대 출시연도를 혼동하지 않습니다.

`photos/sources.json`과 게임의 **사진 출처**에 사진별 제목·저작자·원본 URL·라이선스·변경 내용을 기록했습니다. 사진은 원본 구도를 유지하며 축소·WebP 변환했습니다. 각 사진의 CC BY-SA, CC BY 또는 CC0 조건을 따릅니다. 사진 라이선스는 게임 코드와 별도로 적용됩니다. 재배포 시 이 목록과 원본 라이선스 링크를 함께 유지하세요.

출시연도 문제는 제조사 자료로 확인한 모닝 JA(2017), 아반떼 AD(2015)·CN7(2020), 그랜저 IG(2016)·GN7(2022)만 사용합니다. **개별 차량의 정확한 연식은 사진만으로 판별하지 않으며, 문제는 해당 세대의 최초 출시연도를 묻습니다.** 사진 원본 메타데이터는 `tools/metadata`에 보관합니다.

사진 갱신 도구: Python + Pillow 환경에서 `python -X utf8 tools/collect_photos.py`. 실행 시 기존 메타데이터와 이미지를 재사용하며 필요한 자료만 가져옵니다. 실행 환경에 따라 검토 시트의 `malgun.ttf` 경로를 조정하세요. 새 사진은 `tools/photo-review.jpg`를 열어 차종과 구도를 확인해야 합니다.

## 기록과 개인정보

- 이름·진단명·계정 정보를 받지 않으며 게임 자체에서 학습 기록을 외부 전송하지 않습니다.
- `localStorage`의 `car-clock-garage/v1`에 경험치·선택 자동차·현재 문제·오답·힌트·설정·누적 횟수·최근 2,000문제의 상세 기록을 저장합니다.
- 새로고침 후 ‘이어서 출발하기’로 계속합니다. 같은 주소·같은 브라우저에서 이어집니다. 데이터 삭제·시크릿 모드 종료 등에 대비해 **선생님 설정 → 기록 백업 저장**을 사용하세요. JSON 백업은 진행·설정까지, CSV는 상세 학습 기록만 포함합니다.
- 백업은 검증 후 요약을 보여 주며, 현재 기록을 먼저 백업할 수 있습니다. 불러오면 기존 기록과 합치지 않고 바꿉니다.
- 손상된 기존 기록은 자동으로 덮어쓰지 않습니다. 저장 불가 상태에서는 안내를 표시하고 임시 진행·파일 백업을 지원합니다. 여러 탭에서 기록이 바뀌면 이전 탭의 진행을 멈춰 덮어쓰기를 방지합니다.
- 교사용 설정은 수업 편의를 위한 화면이며 비밀번호로 보호되는 관리 기능이 아닙니다.

## 검증

저장소 루트에서 `node --test tests/car-clock-garage.test.js`.

현재 환경의 Work 설정에서 로컬 브라우저 제어가 비활성화되어 실제 브라우저 화면·클릭·글자 배치의 시각 검증은 수행하지 못했습니다. 사진 검토 시트 대조와 게임 로직·자료·DOM 동작 검증을 별도로 수행했습니다.
