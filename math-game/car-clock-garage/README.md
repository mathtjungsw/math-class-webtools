# 부릉부릉 차고

자동차 사진을 보고 차종과 출시연도를 맞히고, 자동차 5문제마다 아날로그 시계 1문제를 푸는 노트북 중심 게임입니다. 사진 카탈로그는 국산차와 일본 경차 56종을 포함해 차종 선택지 126개, 사진 240장입니다. 기본은 차종 4지선다 + 출시연도 4지선다와 5분 단위 시계입니다.

## 실행

### Google 웹앱

[부릉부릉 차고 열기](https://script.google.com/macros/s/AKfycbzICkBqFPD5Xy4Jm25_xRXwE4KncSg7xjHAycgrM0h1SxoVgmoVCKNv38Zr392VgXw/exec) — Google 로그인 없이 사용할 수 있습니다. 처음이면 ‘새 아이디 만들기’, 저장한 기록이 있으면 같은 아이디로 ‘이어서 하기’를 누르세요. 자동차 사진은 GitHub Pages의 정적 이미지로 불러옵니다.

### 로컬·오프라인 버전

`index.html`을 브라우저로 열거나 아래 한 파일 버전을 사용하세요. 이 버전은 같은 브라우저에 진행 기록을 저장하며 Google 웹앱의 아이디 기록과 동기화되지 않습니다.

한 파일 버전은 저장소 루트에서 `python -X utf8 math-game/car-clock-garage/tools/build_standalone.py`로 생성합니다. `outputs/car-clock-garage/부릉부릉-차고.html`에 사진·코드·출처를 모두 포함하므로 이 파일만 복사해 실행할 수 있습니다. 브라우저 저장은 주소마다 별도이므로 버전·위치를 옮길 때는 JSON 백업으로 기록을 옮기세요.

저장소 루트에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/math-game/car-clock-garage/`로 접속하거나, 기존 저장소와 함께 GitHub Pages에 배포할 수 있습니다. 파일로 직접 연 경우와 HTTP·HTTPS로 연 경우의 브라우저 저장 공간은 서로 다릅니다. 파일 주소에서의 저장 동작은 브라우저에 따라 다를 수 있어 수업에서는 HTTP·HTTPS 접속을 권장합니다.

## 게임과 보상

- 자동차 사진에서 차종과 출시연도를 각각 하나씩 고른 뒤 ‘정답 확인’을 누릅니다. 둘 다 맞혀야 자동차 한 문제를 **완료**합니다. 자동차 5문제를 완료하면 시계 1문제가 나옵니다.
- 일본 경차 사진은 요청에 따라 출시연도를 묻지 않습니다. 차종만 고르면 됩니다.
- 자동차 처음 정답 +10 XP, 시계 처음 정답 +20 XP. 힌트 사용·오답 후 정답은 각각 +5 XP, +10 XP입니다. 반복 클릭·재로딩은 경험치를 중복 지급하지 않습니다.
- 다음 문제는 학생이 버튼을 눌러 넘깁니다. 시간제한과 경험치 차감은 없습니다.
- 모닝 → 레이 → 아반떼 → K5 → 아이오닉 5 → 쏘렌토 → 그랜저 → G80 → GV80의 9단계 차고 보상입니다. 기존 자동차도 계속 선택할 수 있습니다.
- 차종·출시연도는 각각 2~4개 선택지로 조절할 수 있습니다. 기본 4개이며, 차종 오답은 비슷한 종류의 차를 우선하고 출시연도 오답은 가까운 연도와 같은 차의 다른 세대를 우선합니다. 한 가지만 맞으면 해당 문제는 완료되지 않고 다시 고를 항목을 안내합니다. 시계는 5분·정각/30분·정각으로 조절할 수 있습니다. 설정은 다음 문제부터 적용됩니다.
- 시침은 분에 따라 이동합니다. 시계는 SVG로 직접 그려 외부 이미지가 필요하지 않습니다.
- 정답 효과음은 기본 해제입니다. 화면 효과를 끌 수 있고 시스템의 동작 줄이기 설정도 따릅니다.

## 사진·연도 자료

차종 선택지 126개와 사진 240장입니다. 현대·기아·제네시스뿐 아니라 쉐보레·대우·르노삼성·쌍용과 혼다·스즈키·다이하츠·닛산·미쓰비시·스바루·마쓰다 차종을 포함합니다. 에쿠스·스타렉스 계열, K7, SM6, 아슬란, 벨로스터, 말리부, 엑시언트 등 현재 단종된 모델도 포함됩니다. 여러 세대가 확인되는 모델은 서로 다른 세대 사진을 냅니다.

`photos/sources.json`과 게임의 **사진 출처**에 사진별 제목·저작자·원본 URL·라이선스·변경 내용을 기록했습니다. 사진은 원본 구도를 유지하며 축소·WebP 변환했습니다. 각 사진의 CC BY-SA, CC BY 또는 CC0 조건을 따릅니다. 사진 라이선스는 게임 코드와 별도로 적용됩니다. 재배포 시 이 목록과 원본 라이선스 링크를 함께 유지하세요.

출시연도를 묻는 사진 127장에는 제조사·모델 자료의 연도를 연결했습니다. `release-years.json`과 사진 출처 화면에서 근거를 확인할 수 있습니다. **문제의 출시연도는 사진 속 세대가 국내에서 처음 출시된 해입니다.** 생산연도·촬영연도·해외 모델연도와 구분합니다. 일본 경차 사진 109장에는 연도 문제가 없습니다. 요청된 세부 트림 중 자유 이용이 허용된 사진을 찾기 어려운 경우에는 식별되는 기본 차종 사진으로 냅니다.

사진 갱신 도구: Python + Pillow 환경에서 `python -X utf8 tools/collect_photos.py`. 실행 시 기존 메타데이터와 이미지를 재사용하며 필요한 자료만 가져옵니다. 실행 환경에 따라 검토 시트의 `malgun.ttf` 경로를 조정하세요. 새 사진은 `tools/photo-review.jpg`를 열어 차종과 구도를 확인해야 합니다.

## 기록과 개인정보

- Google 웹앱은 아이디 2~20자(한글·영문·숫자·`_`·`-`)로 기록을 저장합니다. ‘이어서 하기’에서 같은 아이디를 쓰면 다른 기기에서도 이어 할 수 있습니다. ‘이재욱’ 아이디는 0 경험치로 준비되어 있습니다.
- 비밀번호 없이 아이디만 사용하므로 같은 아이디를 아는 사람은 해당 기록을 이어 할 수 있습니다. 요청한 ‘이재욱’ 아이디는 이미 준비되어 있습니다. 진행 저장에는 경험치·현재 문제·설정·최근 퀴즈 기록이 들어갑니다. 민감한 개인 정보나 진단 정보는 받지 않습니다. 스프레드시트 자체는 소유자 계정에 비공개로 저장되며 방문자가 직접 열 수 없습니다.
- Google 웹앱은 진행이 바뀌면 해당 아이디의 행만 저장하고, 전체 기록표를 매번 내려받지 않습니다. 화면은 일정 시간 조용해지면 저장을 묶어 보내며, 네트워크가 끊기면 기기의 임시 기록으로 복구를 시도합니다.
- 로컬 버전은 `localStorage`에 경험치·선택 자동차·현재 문제·오답 조합·힌트·설정·최근 2,000문제의 기록을 저장합니다. 기존 브라우저 기록은 백업·불러오기를 지원하며 다른 브라우저와 자동 동기화되지 않습니다.
- Google 웹앱의 아이디 진행 기록과 로컬 `localStorage` 기록은 별도입니다. 기록 손실에 대비해 **선생님 설정 → 기록 백업 저장**을 사용하세요. JSON은 진행·설정까지, CSV는 상세 학습 기록을 담습니다.
- 백업은 검증 후 요약을 보여 주며, 현재 기록을 먼저 백업할 수 있습니다. 불러오면 기존 기록과 합치지 않고 바꿉니다.
- 손상된 기존 기록은 자동으로 덮어쓰지 않습니다. 저장 불가 상태에서는 안내를 표시하고 임시 진행·파일 백업을 지원합니다. 여러 탭에서 기록이 바뀌면 이전 탭의 진행을 멈춰 덮어쓰기를 방지합니다.
- 교사용 설정은 수업 편의를 위한 화면이며 비밀번호로 보호되는 관리 기능이 아닙니다.

## 검증

저장소 루트에서 `node --test tests/car-clock-garage.test.js tests/car-clock-cloud.test.js`.

Google 로그인 없는 공개 엔드포인트에서 아이디 생성·이어 하기, 5문제 후 시계, 저장·재접속, 중복 저장 방지와 다른 기기의 오래된 기록 덮어쓰기 방지를 확인했습니다. 사진은 contact sheet로 차종을 확인했습니다. 현재 Work 설정에서 로컬 브라우저 제어가 꺼져 있어 최종 배포본의 실제 화면 캡처 검증은 수행하지 못했습니다.
