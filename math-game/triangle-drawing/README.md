# 삼각형 그리기 게임

주사위와 점판을 활용해 예각삼각형, 직각삼각형, 둔각삼각형을 만드는 수학 게임 웹툴입니다.

## 수업 활용

- 대상 개념: 삼각형의 내각, 예각삼각형, 직각삼각형, 둔각삼각형
- 추천 인원: 2~6명
- 준비물: 교사용 화면 또는 모둠별 기기
- 핵심 활동: 주어진 조건을 만족하는 세 점을 찾고, 만든 삼각형의 종류를 확인합니다.

## 게임 규칙

1. 참가자 수를 2~6명 중 선택하고 게임을 시작합니다.
2. 자기 차례에 주사위를 굴립니다.
3. 숫자 주사위 3개는 선택해야 할 점의 숫자를 정합니다.
4. 종류 주사위 1개는 이번 차례에 만들어야 할 삼각형의 종류를 정합니다.
   - 1, 2: 예각삼각형
   - 3, 4: 직각삼각형
   - 5, 6: 둔각삼각형
5. 게임판에서 숫자 주사위 결과와 같은 점 3개를 선택합니다.
6. 선택한 세 점이 목표 종류의 삼각형이면 확정됩니다.
7. 새 삼각형의 선이 이미 만들어진 삼각형의 선을 지나가면 해당 참가자는 탈락합니다.
8. 더 만들 수 없다고 판단하면 기권할 수 있습니다.

## 화면 기능

- 참가자 수 선택: 2~6명
- 선 색상 선택: 참가자별 색상 또는 삼각형 종류별 색상
- 가능한 수 보기: 현재 주사위 조건에 맞는 삼각형 후보 하나를 노란색으로 표시
- 확대/축소: 큰 교실 화면이나 작은 기기에서 게임판 크기 조절
- 완성 기록: 만든 사람, 삼각형 종류, 사용한 점 숫자 확인

## 판정 방식

- 세 점이 일직선이면 삼각형으로 인정하지 않습니다.
- 세 변의 길이 제곱을 비교해 예각, 직각, 둔각삼각형을 판정합니다.
- 목표 종류와 다른 삼각형을 선택하면 탈락시키지 않고 다시 선택하도록 안내합니다.
- 이미 그어진 선과 새 선이 교차하거나 겹치면 탈락 처리합니다. 단, 기존 꼭짓점과 새 꼭짓점이 만나는 것은 허용합니다.

## 파일

- `index.html`: 게임 화면 구조
- `style.css`: 게임 UI 스타일
- `app.js`: 주사위, 점 선택, 삼각형 판정, 선 교차 판정, 진행 상태 관리
