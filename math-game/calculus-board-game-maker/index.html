      CLASS MANUAL

      미적분 보드게임 제작기 설명서

      4차시 모둠 프로젝트를 위한 교사·학생 공용 안내

      01

      수업 목표

      다항함수의 미분·적분 개념을 문제로만 나열하지 않고 이동 경로, 점수, 보상과 선택이 연결된 게임 시스템으로 재구성합니다. 다른 모둠이 규칙만 읽고도 플레이할 수 있는 완성도를 목표로 합니다.

      02

      권장 4차시 흐름

      1. 1차시 핵심 재미, 역할, 사용할 미적분 주제 정하기
      2. 2차시 보드·카드·규칙의 첫 버전 만들기
      3. 3차시 실물 재료 제작과 반복 플레이 테스트
      4. 4차시 오류 수정, 인쇄·완성, 동료 플레이와 피드백
      03

      학생 제작 순서

      기획 → 보드 만들기 → 카드/문제 만들기 → 규칙 정리 → 플레이 테스트 → 인쇄/공유 순서로 진행합니다. 내용이 입력된 카드에서 최소 5개 미적분 하위 주제를 사용해야 합니다.

      04

      검사기와 자동 판정의 범위

      도달 불가능한 칸, 정답 없는 문제, 빈 규칙과 점수 불균형을 보조 점검합니다. 객관식·단답형은 등록 문자열과 정확히 같은지만 비교하며, 식의 동치·설명형 답·사용자 승리 규칙은 모둠 또는 교사가 직접 판정합니다.

      05

      완성 전 확인

      • 규칙만 읽은 다른 모둠도 질문 없이 시작할 수 있는가?
      • 어려운 문제의 점수와 우회 경로의 이득이 균형적인가?
      • 수학적 내용·흥미·재료 완성도를 각각 점검했는가?
      • 공유 JSON에 이름·학번 같은 개인정보가 없는가?
