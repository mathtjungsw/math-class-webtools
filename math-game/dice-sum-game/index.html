HOW TO PLAY

주사위 눈 합 게임

  1. 참가 학생을 2~4명으로 정하고, 각자의 표에서 정해진 수만큼 칸을 채웁니다.
  2. 같은 열에서는 아래 칸부터 차례로 채워야 합니다.
  3. 전략을 확정한 뒤 한 번에 던질 주사위 묶음을 1~10개로 정합니다.
  4. 각 묶음의 눈의 합에 해당하는 열에서 모든 학생의 칸 하나가 자동으로 X 표시됩니다.
  5. 여러 묶음은 기록에 표시된 순서대로 처리하며, 모든 칸을 먼저 X로 바꾼 학생이 승리합니다.
