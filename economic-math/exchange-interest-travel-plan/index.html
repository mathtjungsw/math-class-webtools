최종 제출 보고서

선택한 5박 6일 일정과 계산 결과를 확인한 뒤 독립된 HTML 파일로 저장하세요.

학급·번호·이름이 모두 입력되어야 저장·인쇄·복사할 수 있습니다.
입력 내용은 이 브라우저에 자동 임시 저장됩니다. 공용 기기에서는 제출 후 ‘처음부터’를 눌러 내용을 지워 주세요.

웹툴 사용 방법

  1. 필수 항목인 학급·번호·이름을 입력하고 기준연도를 확인합니다.
  2. 20개국 중 여행지를 선택한 뒤 항공권·숙소·준비 패키지를 고릅니다.
  3. 6일 동안 오전·오후 관광지와 하루 식사·교통 방식을 선택합니다.
  4. 무작위로 배정된 원화 강세·기준·원화 약세 시나리오와 10년 후 비용의 계산과정을 확인합니다.
  5. 예비비와 상품 선택 기준을 정한 뒤 월 납입액을 바꾸어 가상 적금상품을 비교합니다.
  6. 선택 결과로 완성된 문장을 점검한 뒤 제출용 HTML 파일을 저장합니다.
자료 성격: 실제 관광지 명칭과 공개된 여행비 수준을 참고하되, 모든 비용은 수행평가용으로 반올림·가상화했습니다. 결과는 실제 여행 견적이 아닙니다.
