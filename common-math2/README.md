## 통합 기준

1. 같은 수학적 대상을 같은 방식으로 조작하는 도구는 한 프로그램의 탭으로 묶었다.
2. 개념 형성, 표현 연결, 적용의 순서가 드러나도록 탭을 배열했다.
3. 교과서 프로젝트가 핵심 개념을 실제 상황에 적용하게 하면 관련 통합 도구의 마지막 탭으로 남겼다.
4. 배경 이야기만 다르고 조작과 결론이 같은 도구는 더 직접적인 도구 하나로 대표시켰다.
5. 공통수학2의 핵심 학습보다 별도 과학·통계 모형의 가정이 더 큰 도구는 게시 대상에서 제외했다.

## 별도 게시에서 제외한 대표 유형

- 같은 개념의 상황만 바꾼 도구: 건축 직선, 멀리뛰기, 평행도로, 컬링, 위성 통신, 게임 캐릭터 이동, 할인쿠폰, 지도 좌표 변환
- 더 강한 통합 탭에 흡수된 미세 기능: 좌표 평균, 기울기 삼각형, 수직선 예외, 수선의 발, 접선 탄생 순간, 원소 개수, 공집합, 부정 스위치
- 교육과정 핵심에서 벗어나거나 별도 가정이 큰 도구: 3차원 모션 캡처, 와이파이 신호 지도, 데이터 군집, 비파괴검사 파형

제외는 원본 파일 삭제가 아니라 메인 웹툴 모음에 별도 카드로 게시하지 않는다는 뜻이다.
