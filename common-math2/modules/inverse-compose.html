합성으로 원상복구

f와 f⁻¹의 왕복 및 합성함수의 반대 순서 되감기를 함수 경로로 확인합니다.

1. 왕복 함수 선택

2. 항등함수 확인

X에서(f⁻¹∘f)(x)=x
Y에서(f∘f⁻¹)(y)=y
역함수의 역함수(f⁻¹)⁻¹=f

항등함수는 모든 입력을 자기 자신으로 보내는 함수이며 상수 1이 아닙니다.

3

왕복 경로

두 왕복 경로는 시작하는 집합이 다릅니다.

4. 합성함수 되감기

x → f → z → g → y
y → g⁻¹ → z → f⁻¹ → x
(g∘f)⁻¹=f⁻¹∘g⁻¹

5. 문제 해결

마지막에 적용한 함수부터 거꾸로 되돌립니다.

도움말

f⁻¹∘f는 X에서의 항등함수이고, f∘f⁻¹는 Y에서의 항등함수입니다.

합성함수 g∘f를 되돌릴 때는 마지막에 적용한 g부터 g⁻¹로 되돌리고, 이어서 f⁻¹을 적용합니다.

교과서 115~119쪽의 역함수 개념을 바탕으로 구성한 학습용 도구입니다. 입력값은 브라우저 안에서만 처리됩니다.
