Ⅴ. 함수와 그래프 · 01 함수

일대일 레이더

수평선을 위아래로 움직여 같은 함숫값을 만드는 서로 다른 입력이 있는지 탐지합니다.

관찰 → 예측 → 조작 → 확인 → 설명

일대일 판정

x₁≠x₂이면 f(x₁)≠f(x₂)
동치: f(x₁)=f(x₂)이면 x₁=x₂
검사 구분

수직선: 함수 여부
수평선: 일대일함수 여부

동아출판 2022 개정 고등학교 공통수학2, Ⅴ-01 함수(106~110쪽) 개념 흐름에 맞춘 오프라인 학습 웹툴

도움말

수평 레이더를 위아래로 움직여 같은 함숫값을 만드는 입력의 개수를 확인하세요.

수평선과 두 점 이상에서 만나면 서로 다른 입력이 같은 함숫값을 가지므로 일대일함수가 아닙니다. 일대일대응은 일대일함수이면서 치역과 공역이 같은 함수입니다.

공역을 바꿔도 함수식과 실제 치역은 자동으로 바뀌지 않을 수 있습니다.
