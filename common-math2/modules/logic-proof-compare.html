대우 후보

대우는 결론 q를 부정한 ~q에서 출발하여 가정 p를 부정한 ~p로 갑니다.

직접 증명: p → q

대우 증명: ~q → ~p

핵심 비교

직접 증명
p를 가정 → 성질 적용 → q
대우 증명
~q를 가정 → 성질 적용 → ~p
대우가 참 → 원래 명제도 참
주의
~p→~q는 대우가 아닙니다. 귀류법은 명제의 부정을 가정해 모순을 이끌어 내는 다른 방법입니다.

도움말

직접 증명은 p가 참이라고 가정하고 q를 이끌어 냅니다. 대우 증명은 ~q가 참이라고 가정하고 ~p를 이끌어 냅니다.

  1. p와 q를 확인합니다.
  2. 대우가 정확히 ~q→~p인지 고릅니다.
  3. 카드를 끌거나 위·아래 버튼으로 배열하고 각 단계의 근거를 선택합니다.
  4. 두 방법의 단계 수와 자연스러움을 비교합니다.

대우 증명에서는 모순을 만들 필요가 없습니다. ~q에서 ~p를 직접 이끌어 내면 됩니다.
