제곱근 교점 검증기

양변을 제곱해 얻은 후보해를 정의역·부호 조건·원래 식에 다시 대입하여 실제 교점과 무연근을 구분합니다.

관찰 → 예측 → 조작 → 계산 확인 → 성질 설명

대수 계산 단계

2x+t=√(x-2)

그래프와 실제 교점

정확한 두 교점 범위: −4≤t<−31/8

후보해 검증표

후보 xx≥22x+t≥0제곱한 식원래 식판정

추가 무리방정식 검증

왜 무연근이 생길까요?

A=B ⇒ A²=B², 그러나 A²=B² ⇏ 항상 A=B

제곱하면 A=B뿐 아니라 A=−B인 경우도 함께 들어올 수 있습니다. 오른쪽 제곱근은 항상 0 이상이므로, 제곱하기 전 왼쪽 2x+t도 0 이상이어야 합니다.

도움말

  1. 원래 방정식의 정의역 x≥2를 확인합니다.
  2. 오른쪽 제곱근이 0 이상이므로 왼쪽 2x+t≥0을 확인합니다.
  3. 양변을 제곱해 이차방정식 후보해를 구합니다.
  4. 후보해를 원래 식에 다시 대입합니다.
  5. 제곱한 식만 만족하고 원래 식을 만족하지 않으면 무연근입니다.
