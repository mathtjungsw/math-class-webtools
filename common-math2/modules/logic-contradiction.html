4단계 · 결론 내리기

모순이 발생하면 처음 가정한 부정이 거짓이고 원래 명제가 참입니다.

귀류법 구조

  1. 원래 명제 r 확인
  2. 부정 ~r을 참이라고 가정
  3. 정의·성질로 추론
  4. 양립할 수 없는 두 결과 발견
  5. ~r은 거짓
  6. r은 참

도움말

귀류법은 증명하려는 명제가 참이라고 직접 밀어 가는 대신, 그 부정을 참이라고 가정합니다.

  1. 정확한 부정을 선택합니다.
  2. 선행 조건을 만족하는 추론 카드를 차례로 선택합니다.
  3. 서로 동시에 참일 수 없는 두 문장을 고릅니다.
  4. 모순이므로 처음의 부정이 거짓, 원래 명제가 참이라고 결론 내립니다.

√2 증명에서는 유리수를 √2=n/m으로 나타낼 때 m,n이 서로소인 두 자연수라는 조건이 핵심입니다.
