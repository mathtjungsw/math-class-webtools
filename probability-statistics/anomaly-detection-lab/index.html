    ANOMALY DETECTION LAB · O11

    수학 수업 웹툴 모음 · 확률과 통계

    경고는 질문의 시작입니다. 자료의 맥락, 기저율, 오류 비용과 후속 조사 절차를 함께 판단하세요.
    USER & TEACHER MANUAL

    이상 징후 탐지 연구소 설명서

    정상 자료의 흔들림을 먼저 관찰하고, 탐지 기준을 직접 정한 뒤 오류의 종류와 비용을 비교하는 수업용 도구입니다. 실제 사람을 평가하는 용도로 사용하지 않습니다.

    빠른 사용 순서

    1. 합성 상황과 조건 선택기저율·정상 변동·이상 신호·표본 수·분포 이동을 정하고 시드로 자료를 만듭니다.
    2. 라벨 없이 관찰시계열·산점도·히스토그램을 바꾸고 점을 클릭해 이상 의심 자료를 고릅니다.
    3. 규칙과 임계값 설정다섯 방법 중 하나를 선택하고 낮은 선과 높은 선의 경고 수를 예상합니다.
    4. 정답 공개와 평가TP·FP·TN·FN, 정확도·정밀도·재현율·특이도·거짓 경보율을 확인합니다.
    5. 비용 미션과 토론FP·FN 비용을 바꾸고 모둠의 기준 A·B를 저장해 결정 근거를 비교합니다.

    탐지 방법 읽기

    고정 거리
    |값−평균|이 정한 거리보다 큰지 비교
    z점수
    평균과의 차이를 표준편차 단위로 비교
    IQR
    Q1−k·IQR과 Q3+k·IQR 울타리 사용
    이동평균
    현재 값을 바로 앞 최근 구간과 비교
    두 특성
    두 z점수를 합친 2차원 거리 사용

    지표 해석

    정밀도

    재현율

    특이도
    실제 정상 중 통과시킨 비율
    거짓 경보율
    실제 정상 중 잘못 경고한 비율
    오류 비용
    FP×FP 비용 + FN×FN 비용

    키보드·파일·재현 기능

    • 그래프에 초점을 둔 뒤 ← →로 점을 이동하고 Space 또는 Enter로 선택합니다.
    • 같은 조건과 같은 시드는 같은 합성 자료를 만듭니다. 활동 JSON은 자료·선택·임계값·비용·기록을 함께 저장합니다.
    • CSV 열 이름은 value, feature2, time, label을 권장합니다. label은 1/0, true/false, 이상/정상 형식을 인식합니다.
    • 실제 금융·건강·학생 개인정보 대신 합성 또는 충분히 익명화한 자료만 사용하세요.
