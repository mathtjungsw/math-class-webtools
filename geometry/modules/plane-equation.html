관찰 기록

도움말

  1. 평면 만들기: 점 A와 영벡터가 아닌 법선벡터 n을 조절하면 A를 지나고 n에 수직인 평면이 만들어집니다.
  2. 점 P: P는 항상 평면 위를 움직이며, AP·n=0이 실시간으로 확인됩니다.
  3. 실수배: k≠0일 때 kn은 같은 평면의 법선벡터입니다. k=0은 법선벡터가 될 수 없어 경고합니다.
  4. 점과 평면 사이의 거리: 측정점 Q에서 평면에 내린 수선의 발 H와 선분 QH를 표시하고, |ax₀+by₀+cz₀+d|/√(a²+b²+c²)를 계산합니다.
  5. 절편: 평면이 각 축과 만나는 경우 x절편, y절편, z절편을 표시합니다. 해당 계수가 0이면 그 축과 평행하여 절편이 없을 수 있습니다.
  6. 탐구 순서: A 이동 → n 방향 변경 → P 이동 → 내적 확인 → k 변경 → 방정식과 절편 관찰.

교과서 155~157쪽의 한 점과 법선벡터, 벡터방정식 (p−a)·n=0, 좌표방정식 ax+by+cz+d=0을 바탕으로 구성했습니다.
